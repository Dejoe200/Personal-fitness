# Steady

A fitness tracking app built with Tailwind CSS and Supabase.

## Features

- Email and password authentication
- Workout logging, daily streaks, and 7-day progress
- Fitness goals tracker (add, complete, delete)
- Cloud sync with Supabase

## Setup

1. Clone or download the repository.
2. Open `index.html` and replace the placeholder credentials with your Supabase project details:
